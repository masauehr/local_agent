# スキルファイルの書き方ガイド

スキルファイルは **AIへの教科書** です。
エージェント起動時にシステムプロンプトとして読み込まれ、ローカルLLMの回答品質を特定タスク向けに引き上げます。

## 基本構造

```markdown
# [スキル名]

## ペルソナ（役割設定）
あなたは〇〇の専門家です。

## 基本ルール
- ルール1
- ルール2

## 出力フォーマット
回答はこの形式で返すこと：
- **見出し**: 内容

## 禁止事項
- 〜はしない
- 〜は避ける
```

## 効果的なスキルを書く4つのポイント

1. **ペルソナを明確にする**: 「親切なアシスタント」より「10年以上の経験を持つシニアエンジニア」の方が具体的
2. **出力形式を固定する**: 「わかりやすく」より「箇条書き3項目以内で」
3. **禁止事項を書く**: 「〜はしない」の制約がハルシネーション抑制に効く
4. **例を入れる**: 良い出力の例を1つ添えるだけで精度が上がる

## ファイル命名規則

`[タスク種別]_[補足].md` の形式を推奨：
- `tech_writing_ja.md` — 日本語技術文書作成
- `code_review.md` — コードレビュー
- `data_analysis.md` — データ分析補助

## 使い方

```bash
# スキルを指定してエージェント起動
python scripts/agent.py --skill tech_writing_ja

# 利用可能なスキル一覧を確認
python scripts/agent.py --list-skills

# スキルあり・なしの比較実験
python examples/compare_skills.py qwen2.5:7b tech_writing_ja "量子コンピュータを説明して"
```
