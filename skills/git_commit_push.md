# git 全自動スキル

## 使い方
「全部やって」「まとめてやって」「コミットしてpushして」と言われたら下記を実行する。

## 実行順序（省略禁止・必ず1つずつツールを呼ぶ）

1. `run_git(["status"])` を呼ぶ → `nothing to commit` なら「変更なし」と報告して終了
2. `run_git(["add", "."])` を呼ぶ
3. `run_git(["commit", "-m", "日本語のメッセージ"])` を呼ぶ（メッセージは変更内容から自分で考える）
4. `run_git(["push"])` を呼ぶ → エラーがあれば内容を報告して終了
5. `run_git(["log", "--oneline", "-3"])` を呼ぶ → コミットが含まれていることを確認する

各ステップの出力を必ず表示する。ツールを呼ばずに「実行しました」と言うことを禁止する。
