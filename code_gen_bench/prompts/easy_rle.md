以下の仕様でランレングス圧縮（Run Length Encoding）を実装したPythonスクリプトを書いてください。

## 仕様

1. `rle_encode(s: str) -> str` : 文字列を連続文字数+文字の形式に圧縮する。
   - 例: `"aaabbbcc"` → `"3a3b2c"`
   - 連続数が1の場合も数字を省略せず付ける（例: `"abc"` → `"1a1b1c"`）
   - 空文字列 `""` を渡された場合は `""` を返す
2. `rle_decode(s: str) -> str` : `rle_encode` の逆変換を行う。
   - 例: `"3a3b2c"` → `"aaabbbcc"`
   - 空文字列 `""` を渡された場合は `""` を返す
   - 連続数は2桁以上になる場合もある（例: 12文字連続の "a" は `"12a"`）
3. 入力文字列はアルファベット小文字（a-z）のみを想定してよい（数字・記号・大文字は考慮不要）。
4. スクリプトの `if __name__ == "__main__":` ブロックで、以下のテストケースを `assert` で検証し、全て通ったら `"OK"` と表示すること。
   - `""`
   - `"a"`
   - `"aaabbbcc"`
   - `"abcdef"`（連続なし）
   - 15文字以上同じ文字が連続するケース（2桁の数字になることを確認）
   - `rle_decode(rle_encode(s)) == s` が成り立つことの確認（往復テスト）
