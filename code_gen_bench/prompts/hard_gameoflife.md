以下の仕様で、コンウェイのライフゲーム（Conway's Game of Life）をシミュレートするPythonスクリプトを書いてください。

## 仕様

1. グリッドは幅 `width`・高さ `height` を指定できるようにする。
2. セルの生死は標準のライフゲームのルールに従う。
   - 生きたセルは、隣接8マスの生存数が2または3のときだけ次世代も生存する
   - 死んだセルは、隣接8マスの生存数がちょうど3のとき次世代で誕生する
   - グリッドの端は「外側は全て死んでいる」ものとして扱う（トーラス状にラップしない）
3. クラス `GameOfLife` を実装し、以下を持つこと。
   - コンストラクタ `__init__(self, width: int, height: int, alive_cells: set[tuple[int, int]])` : `alive_cells` は初期状態で生きているセルの `(x, y)` 座標集合
   - メソッド `step(self)` : 現在の状態を次の世代に更新する（内部状態を書き換える）
   - メソッド `render(self) -> str` : 現在のグリッドをASCIIアートの文字列で返す。生存セルは `#`、死亡セルは `.` で表す。1行が1つの `y` に対応し、行末に改行を含める
4. `if __name__ == "__main__":` ブロックで、以下を行うこと。
   - 幅15×高さ10のグリッドを作成
   - 初期パターンとして「グライダー」（座標 `(1,0), (2,1), (0,2), (1,2), (2,2)`）を配置
   - 世代0から世代4まで、各世代の `render()` 結果を「Generation N」という見出し付きで標準出力に表示する（`step()` を呼んでから次の世代を表示）
