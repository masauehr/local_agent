以下の仕様で、簡易Markdown記法をHTMLに変換するPythonスクリプトを書いてください。

## 仕様

1. 関数 `markdown_to_html(md: str) -> str` を実装する。入力は複数行のMarkdown文字列。
2. 対応する記法:
   - 見出し: 行頭の `#` の数（1〜6個）に応じて `<h1>`〜`<h6>` に変換する（例: `## タイトル` → `<h2>タイトル</h2>`）
   - 太字: `**text**` を `<strong>text</strong>` に変換する（1行内に複数出現してもよい）
   - リスト: 行頭が `- ` で始まる行が連続する範囲を `<ul><li>...</li>...</ul>` で囲む
   - リンク: `[表示文字](URL)` を `<a href="URL">表示文字</a>` に変換する
   - 上記のいずれにも該当しない非空行は `<p>...</p>` で囲む
   - 空行は無視する（出力に含めない）
3. `if __name__ == "__main__":` ブロックで、以下のサンプルMarkdownを変換し、結果を標準出力に表示すること。

```
# 見出し1
## 見出し2

これは**太字**を含む段落です。

- リスト項目1
- リスト項目2
- リスト項目3

詳しくは[公式サイト](https://example.com)を参照してください。
```

4. スクリプト単体で `python3 このファイル.py` として実行すればサンプルの変換結果が表示される状態にすること。
