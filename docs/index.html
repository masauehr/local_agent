03

Claude Code経由 ツール呼び出し安定性テスト

総括

生成速度・エージェント安定性ともに最有力
ornith-1.5:35b

コード生成・ツール呼び出しの両テストで最速かつ完走。導入直後のモデルだが今回の実測ではもっともバランスが良い。

実績重視・手堅い選択肢
nemotron-3.5-lightning

コード生成・エージェントタスクとも安定して完走。出力にコードブロック二重ネストの癖がある点だけ後処理側で要注意。

従来の推奨モデルは今も通用するか
qwen3.6:35b-mlx

ツール呼び出しは安定して完走したが、単発コード生成でタイポによる実行時エラーを出した。エージェント用途は健在、単発生成の信頼性はやや後退。

避けたほうがよい用途
qwen3.8:27b-mlx（エージェント用途）

単発コード生成は丁寧だが、Claude Code経由の複数ターンタスクは15分のタイムアウトで完走できず。Dense構造による低速が実運用の障壁になる、という過去の知見をそのまま裏付けた。

コード生成単体の比較と、エージェントとしての比較は別物だった。 qwen3.8はコード生成品質だけ見れば5モデル中トップクラスに丁寧だったが、Claude Code経由のマルチターンタスクでは唯一完走できなかった。 逆にornith-1.5は単発生成・エージェントタスクの両方で速く安定しており、「導入直後だから未知数」という以上の実力を見せた。 単一のベンチマーク軸だけでモデルを選ぶと、実運用で足をすくわれる好例。
